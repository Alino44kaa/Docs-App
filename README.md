Курсовая работа на тему "Веб-приложение для поддержки работы предприятия в области оказания бытовых услуг по ремонту помещений"

Основной задачей данного приложения будет сбор документации и договоров, которые заключались между компанией Constrution company и клиентами.

Функции веб-приложения:
   1 Поиск документов из общего списка 
   2 Добавление документа и редактировать информацию
   3 Оставить комментарий и оценить работу агента
   4 Вход и Регистрация. Смена пароля. Обновление пользоваьеля. Редактировать имя пользователя.
